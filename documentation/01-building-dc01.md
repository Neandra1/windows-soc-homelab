# 01 - Building the Domain Controller

## Objective

The objective of this phase was to build the foundation of the Windows enterprise environment by deploying a Windows Server 2022 virtual machine that would function as the domain controller for the lab.

## Tasks Completed

- Installed Windows Server 2022
- Configured a static IP address
- Renamed the server to **DC01**
- Installed Active Directory Domain Services (AD DS)
- Promoted the server to a Domain Controller
- Created the **homelab.local** Active Directory domain

## Why This Matters

The Domain Controller is the core of a Windows enterprise network. It provides centralized authentication, authorization, directory services, and policy management for domain-joined devices.

## Skills Demonstrated

- Windows Server Administration
- Active Directory Deployment
- Server Configuration
- Static IP Configuration
- Domain Controller Promotion
